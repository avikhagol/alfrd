## Contracts inspected and remaining work

- K2 already freezes selected content per request, retries reuse the snapshot, and unknown IDs / the 128 KiB aggregate limit fail before launch. Do not replace this with client-side injection.
- K3 `GET C/skills` supplies discovered metadata, per-agent adapter/native state, effective arguments and honest effect notes. It does not supply content for the required preview. A future content endpoint must retain project-root, symlink and 64 KiB protections; escaped plain text is a safe preview option.
- S2/S3 register `chat.saved_skills`, `chat.native_skills`, `chat.native_plugins`, `chat.native_mcp`. The project save currently supports the saved-skills enabled switch and Lean, but rejects the three native keys as not stored per project. Chat agent schema/launch propagation currently supports Lean, not independent native options. K3's dry-run specs likewise forward Lean only. Future native toggles require backend wiring and tests, not cosmetic checkboxes.
- S3's `/studio/ui-flags` enforces integer `expected_revision` and returns 409 for stale forms. The chat-settings endpoint currently uses `base_hash`; it does not consume `expected_revision`. Selected IDs cannot currently be saved through S3. A guarded atomic save must cover selection and native controls without losing concurrent changes; do not silently accept an ignored revision field or write the whole stale chat block after a separate flag save.
- `data/chat.js::chatBlock` currently omits `skill_selection`; both dialogs reconstruct chat settings through that serializer. Integration must preserve the selection on ordinary chat edits and round-trip native options, as well as honour disabled/locked flag reasons.
- Future UI must share the chooser between both dialogs, show available/selected wording and aggregate size, separate native Skills/Plugins/MCP from saved skills, describe Lean as a preset, show actual saved effective args, render a safe preview, and retain edits on a 409 while offering explicit reload. Do not automatically retry stale mutations.
