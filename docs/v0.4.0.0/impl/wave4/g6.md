# G6 status icons, legend and keyboard navigation

Date: 2026-10-25. Branch: `v0.4.0.0-wave4`. Starting HEAD: `be4bf20`.

## Implementation

- Existing `mountGraph` renders D3 `statusIcon` markup for runtime nodes. The helper accepts an optional escaped label so dependency/budget explanations survive. Unknown statuses retain a neutral icon and descriptive text; editable workflow drafts retain their existing badges.
- A collapsed, keyboard-accessible legend lists all six D3 states with icons and visible labels, plus keyboard help. Existing D3 status tokens are reused without CSS or palette changes.
- In read-only graphs, arrows pan when no node is selected. Tab/focus selects a node; arrows then move through deterministic layout order, Enter/Space opens it, and Escape clears selection and returns focus to the canvas. Id and owner remain visible on nodes and are included in hover titles. Editable draft keyboard behavior is preserved.
- G4 was deferred and its shared request selector is absent. G6 uses the existing renderer in main/fullscreen chat and does not claim G4 scope/container integration. G5/G7 must preserve the keyboard and focus behavior while extending this renderer.
