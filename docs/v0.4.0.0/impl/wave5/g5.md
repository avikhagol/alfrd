# G5 context menu, overflow and Shift+F10

Date: 2026-10-25. Branch: `v0.4.0.0-wave5`. Starting HEAD: `83e91de` (G4).

## Outcome

Implemented the shared graph task menu in the Chat inspector, fullscreen Chat graph and Workflow chat-session graph. Right-click selects the clicked node; Shift+F10, the ContextMenu key and each node's named overflow button open the same menu. Escape closes the menu, stops propagation to fullscreen dismissal and returns focus to its originating node. Arrow keys, Home and End navigate actions; Tab and focus leaving the menu dismiss it. Editable draft graphs retain their existing behavior. Overflow buttons are siblings of node buttons, avoiding nested interactive controls, and native overflow keyboard activation does not open task details.

The menu consumes F5 `actions(target)`, displaying disabled reasons. It captures row, graph revision, status, latest unit and session context. Retry uses the backend preview and confirms its affected rows. Mutations send `expected_status` and `expected_unit`. Changed local targets refresh before any write; HTTP 409 reloads state and preview while keeping the menu open, without repeating the write. Missing targets and changed sessions close the menu. Late previews cannot reopen a dismissed menu. Preview failures leave mutations unavailable. Orchestrator menus omit task-level Retry/Cancel and retain applicable read actions and Copy ID. Existing owner hover/accessibility text is preserved.

The API adapter opens archived prompt/reply files and logs; View files opens the Chat Files inspector, closing fullscreen first. In the Workflow consumer, View files navigates to the Chat session, where its inspector is available.

Graph updates are queued while the menu is open. Dismissal flushes the newest queued revision when other interactions permit, preserving the viewport and restoring focus to the current node element. The regression test covers reordered pending revisions and Escape propagation; another covers native Enter/Space activation of overflow buttons without opening task details.
