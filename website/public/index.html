ALFRD

Run your pipeline steps, see where every target stands, and pick up where you left off.

ALFRD is a locally run, open source application for command-line pipelines. Define your steps, track progress in a CSV, and explore status, logs, and results in Workflow Studio. Built for radio astronomy, it works with any command-line pipeline.

Get ALFRD and read the documentation

Connect a Google spreadsheet

The optional Google Sheet plugin lets you connect workflow data to spreadsheets you choose or create with ALFRD. You sign in to Google from your locally running app and control which spreadsheets it can access.

Google credentials are stored locally on your machine. Read the privacy policy for the requested permissions, data handling, and how to revoke access.

Explore Workflow Studio

Open the browser-only Workflow Studio, or install ALFRD to run your own pipelines locally.
